# Ресурспак Градостроя

Исходные PNG, pack.mcmeta и таблица `gradostroy:gui` сохранены без перерисовки.
`./gradlew resourcePack` создаёт ZIP с pack.mcmeta в корне, пригодный для клиентской проверки.

U+E001…U+E008 соответствуют MAIN, TERRITORY, PURCHASE, UPGRADES, TREASURY, RESIDENTS, MANAGEMENT, DIPLOMACY.
Для MARKET отдельного изображения пока нет. Исходный metadata указывает диапазон формата [88,0]; совместимость нужно подтвердить клиентом 26.2.

Все изображения уже содержат текст, числа, имена и декоративные кнопки. Они годятся для предпросмотра исходного концепта.
Для рабочего динамического GUI следует отдельно подготовить фон без фиксированных значений и проверить совмещение с серверными слотами.
Без ресурспака GUI использует ванильные предметы, имена и lore. Фоны выключены по умолчанию и применяются только в административном preview.
