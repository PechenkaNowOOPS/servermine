Открой приложенную папку ServerMine-Codex-Bootstrap как рабочую директорию.

Сначала полностью прочитай AGENTS.md, затем CODEX_TASK.md и выполни задачу самостоятельно до конца.

Ключевые требования:
- Java 25, Purpur 26.2, Gradle Kotlin DSL.
- ServerMineEconomy остаётся отдельным плагином и публичным API.
- Gradostroy становится ServerMineCities: внутренне многомодульный проект, но один runtime JAR.
- Не смешивай владение данными: Economy владеет физической валютой и денежными операциями; Cities владеет городами, территориями, ролями, казной, прогрессией и улучшениями.
- Игроки управляют городом через GUI книги; команды Cities только административные.
- Новый город получает 4 чанка.
- Лимиты этапов: 4 / 12 / 24 / 40 / 64.
- Поселение не может купить пятый чанк до перехода в Деревню.
- Новые чанки только соседние.
- Улучшения не дают прямой +N лимит чанков.
- Телепортации на городскую площадь нет.
- Междоменная покупка: reserve -> commit/release через Economy.
- Сохрани GUI-прототип как presentation/resource-pack слой, не как источник данных.

После успешной сборки:
1. git init -b main
2. сделай логические коммиты;
3. если gh установлен и авторизован, создай PRIVATE репозиторий `servermine`, добавь origin и push main;
4. если gh не авторизован — не останавливай локальную работу, а выведи мне точную команду для создания remote после авторизации.

Не спрашивай подтверждения на каждую мелочь. Останавливайся только если требуется внешний секрет/авторизация или есть действительно неоднозначное продуктовое решение, которого нет в AGENTS.md.
