# GradostroyGUI MVP

Первый рабочий прототип GUI для плагина «Градострой» проекта Server Mine.

## Что уже сделано

- Книга управления городом — игровой предмет, открывающий GUI по ПКМ.
- Игровых команд нет: команды `/gradostroygui ...` предназначены только для администрации (`gradostroy.admin`).
- 8 экранов: главное меню, территория, подтверждение покупки, улучшения, казна, жители, управление, дипломатия.
- Нарисованный пиксель-арт интерфейс разрезан на отдельные экраны и встроен в resource pack как bitmap-font background.
- Серверные кнопки поверх визуального интерфейса.
- Защита GUI от shift-click, drag, number-key и любых переносов предметов: весь экран блокируется обработчиком клика/drag.
- Menu Session с UUID игрока, Session ID, типом меню, ревизией города и временем открытия.
- Покупка чанка повторно проверяет ревизию, лимит этапа и баланс казны.
- Подтверждение покупки вынесено в отдельный экран.
- Демонстрационный город сохраняется в `plugins/GradostroyGUI/demo-city.yml`.
- Покупки получают Operation ID и записываются в `audit.log`.
- Без ресурспака меню остаётся функциональным благодаря обычным предметам-кнопкам.

## Целевая среда

- Purpur 26.2 / совместимый Paper API
- Java 25
- Gradle
- Minecraft Java 26.2

## Сборка

Открой папку `plugin` и выполни:

```bash
gradle build
```

или используй Gradle из IDE с Java 25.

Результат появится в:

```text
plugin/build/libs/GradostroyGUI-0.1.0-SNAPSHOT.jar
```

## Установка

1. Собрать JAR.
2. Положить JAR в `plugins/` сервера Purpur.
3. Перезапустить сервер.
4. Установить `GradostroyGUI-ResourcePack.zip` клиентам или разместить его по URL и указать как серверный resource pack.
5. Администратор выдаёт книгу:

```text
/gradostroygui givebook <игрок>
```

6. Игрок открывает интерфейс ПКМ по книге. Команды игроку не нужны.

## Административные команды

```text
/gradostroygui givebook <игрок>
/gradostroygui open <игрок> [menu]
/gradostroygui setdemo <name|stage|chunks|treasury> <значение>
/gradostroygui reload
```

Доступ только с `gradostroy.admin` (по умолчанию OP).

## Этапы и лимиты чанков

В коде уже зафиксирована текущая черновая схема:

- Поселение — 4
- Деревня — 12
- Город — 24
- Столица — 40
- Королевство — 64

Улучшения не увеличивают лимит чанков напрямую. Для дальнейшего расширения нужен следующий этап развития.

## Что пока является прототипом

Этот архив отвечает именно за GUI-слой. Пока не подключены полноценные домены `Cities`, `Economy`, `Protection` и SQLite.

- Покупка чанка меняет демонстрационное число территории, а не реальный claim мира.
- Казна хранится в demo-city.yml, а не в Economy/Cities.
- Список жителей демонстрационный.
- Дипломатия и улучшения пока навигационные экраны.
- Карта соседних чанков пока не вычисляет реальную геометрию города.

Это сделано специально, чтобы сначала можно было запустить и оценить интерфейс, а затем подключить его к настоящей логике «Градостроя» без переделки визуального слоя.

## Resource pack и фон GUI

Фоны находятся в:

```text
resource-pack/assets/gradostroy/textures/font/gui/
```

а таблица glyph'ов — в:

```text
resource-pack/assets/gradostroy/font/gui.json
```

Используются private-use символы `U+E001` ... `U+E008`. Плагин вставляет соответствующий символ в заголовок инвентаря с шрифтом `gradostroy:gui`, поэтому текстура визуально накрывает стандартный контейнер.

Если потребуется точная подгонка под конкретный GUI Scale клиента, меняются `ascent`/`height` в `gui.json` и координаты/размеры исходных PNG, серверную логику трогать не нужно.
