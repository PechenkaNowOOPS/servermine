# Архитектура ServerMineEconomy

```text
Другие плагины
 Cities / HuntingGrounds / Dungeons / Events / Shops
                    |
                    v
             economy-api
             EconomyService
                    |
                    v
          ServerMineEconomy plugin
      +-------------+--------------+
      |             |              |
 CurrencyCodec  MoneyEngine   OperationRepository
      |             |              |
      v             v              v
  PDC + HMAC   PlayerInventory   SQLite WAL
```

## Инварианты

1. Денежная сумма — целое число минимальных единиц (`long`).
2. Любая мутация имеет устойчивый UUID операции.
3. GUI/команда/предмет не являются источником истины.
4. Другие плагины не пишут в БД Economy.
5. Поддельный предмет не участвует в балансе.
6. Неопределённая операция не повторяется автоматически.
7. Bukkit-инвентарь меняется только на main thread.
8. SQL выполняется через выделенный DB executor во время работы сервера.
9. Номинал `1` обязателен: иначе невозможно гарантировать точную сдачу.
10. Городской банк принадлежит Cities, а не Economy.

## Междоменная сага Cities

```text
Cities                    Economy
  |                         |
  |---- reserve(op, 750) -->|
  |<--- RESERVED -----------|
  |                         |
  | commit chunk in Cities  |
  |                         |
  |---- commit(op) -------->|
  |<--- COMMITTED ----------|
```

Если Cities не смог применить изменение:

```text
  |---- release(op) ------->|
  |<--- RELEASED -----------|
```

## Почему нет виртуального личного баланса

В текущей концепции валюта физическая. `physicalBalance()` вычисляет стоимость только подлинных монет в инвентаре онлайн-игрока.

Серверные балансы вроде городской казны являются состоянием соответствующего домена. Economy участвует в фактическом внесении/выводе валюты, но не становится владельцем казны.
