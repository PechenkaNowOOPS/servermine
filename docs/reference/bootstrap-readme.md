# ServerMine — Codex Bootstrap

This folder is intended to be opened directly in Codex.

## What Codex should do

Read `AGENTS.md` first, then execute `CODEX_TASK.md`.

The target is a Git repository for the ServerMine plugin suite with:
- independent `ServerMineEconomy`;
- modular `ServerMineCities` / Gradostroy;
- public APIs for cross-plugin use;
- Java 25 + Purpur 26.2;
- Gradle Kotlin DSL.

## Existing implementations

- `existing/ServerMineEconomy/` — current Economy source baseline.
- `existing/GradostroyGUI/` — current City Management Book GUI/resource-pack prototype.

They are inputs for migration into the final repository structure, not the desired final layout.
