Изучены 73 файла из приложений, включая 10 PNG и ZIP ресурспака. Оригинальные байты сохранены в source-materials.zip, SHA-256 — в input-manifest.json.

ARCHITECTURE — с economy-current-architecture. PROMPT_FOR_CODEX и его копия идентичны.

## Принятые решения при переносе

1. Java API раньше имел toolchain 25, но release 21. Все рабочие модули приведены к Java 25.
2. Динамическая версия Purpur `26.2.build.+` заменена конкретной `26.2.build.2633-stable`.
3. GUI DemoCityRepository выполнял синхронную запись YAML из обработчика клика и менял только счётчик территории. Он сохранён в prototype, но исключён из runtime.
4. Жители, казна, карта и координаты на изображениях являются демонстрационными. В рабочем сервисе они не объявляются настоящим городом.
5. Исходный GUI открывал новый inventory прямо из InventoryClickEvent. Адаптер теперь переносит навигацию на следующий серверный tick.
6. Все переносы GUI отменяются. Навигация допускается только обычным левым кликом, проверяются владелец сессии, текущий holder и срок сессии.
7. BookMeta.addPages в целевом API принимает Adventure Component; импортированная книга исправлена при компиляции.
8. В Economy два одновременных release могли оба перейти к payout независимо от результата SQL-перехода. Добавлен признак владения переходом и проверка победителя; регрессионные тесты покрывают release/release и release/commit.
9. Переполнение суммы payout проверяется до записи inventory. Формула округления charge больше не складывает потенциально переполняющиеся long.
10. Публичный Cities API возвращает readiness=false до реализации персистентности. Никакие демоданные не становятся источником истины.

## Что требует следующей разработки

- Реальные Cities storage/services и устойчивый журнал междоменных операций.
- Серверные тесты сохранения playerdata и журнала Economy при аварии; автоматическое восстановление UNKNOWN не реализовано.
- В примерах нельзя считать общий `EconomyResult.successful()` достаточным доказательством нового резерва: требуется нужное состояние и Cities-журнал.
- Миграции уже выпущенной валюты и ротация ключа отсутствуют; базовый импорт сохраняет имена Economy/PDC.
- Корректность клиентского overlay, GUI Scale, формат ресурспака и блокировка всех переносов должны проверяться на настоящем клиенте.
- На момент подготовки GitHub CLI не найден. Remote не создан; точная команда находится в docs/development/github.md.
