# Прогрессия

| Этап | Название | Лимит чанков |
|---|---|---:|
| SETTLEMENT | Поселение | 4 |
| VILLAGE | Деревня | 12 |
| CITY | Город | 24 |
| CAPITAL | Столица | 40 |
| KINGDOM | Королевство | 64 |

Порядок: SETTLEMENT → VILLAGE → CITY → CAPITAL → KINGDOM.
Город основывается на четырёх чанках. Поселение не покупает пятый чанк до перехода в Деревню.
Даже при неполном/некорректно восстановленном наборе территории стадия SETTLEMENT запрещает покупку.

Числа cap закреплены продуктовым правилом и тестом. Цены, условия повышения и цена чанка — конфигурируемые политики будущего workflow.
`territory.chunk-price` в текущем Cities config служит только предпросмотру.
StageProgression задаёт порядок, но не разрешает бесплатный переход и не выполняет мутацию.

Улучшения не изменяют cap напрямую. Отдельного API для увеличения cap на N нет.
