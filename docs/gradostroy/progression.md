# Прогрессия

| Этап | Название | Лимит чанков |
|---|---|---:|
| SETTLEMENT | Поселение | 4 |
| VILLAGE | Деревня | 12 |
| CITY | Город | 24 |
| CAPITAL | Столица | 40 |
| KINGDOM | Королевство | 64 |

Порядок: SETTLEMENT → VILLAGE → CITY → CAPITAL → KINGDOM.
Город основывается на четырёх чанках. Поселение не покупает пятый чанк до перехода в Деревню.
Даже при неполном/некорректно восстановленном наборе территории стадия SETTLEMENT запрещает покупку.

Числа cap закреплены продуктовым правилом и тестом. Переход SETTLEMENT → VILLAGE подключён через книгу; его стоимость, минимум жителей и минимум чанков задаются в `progression.settlement-to-village` конфигурации Cities.
`territory.chunk-price` пока служит только предпросмотру.
Остальные переходы ещё не подключены. StageProgression задаёт порядок, но сам по себе не разрешает переход и не выполняет мутацию.

Улучшения не изменяют cap напрямую. Отдельного API для увеличения cap на N нет.
