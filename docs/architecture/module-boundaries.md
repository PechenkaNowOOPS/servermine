# Границы экономических модулей

| Компонент | Назначение |
|---|---|
| `economy/economy-api` | Публичные контракты EconomyService, запросы, результаты и состояния |
| `economy/economy-plugin` | Физические монеты, PDC/HMAC, номиналы, операции, резервы, SQLite, админ-диагностика |
| `examples` | Образцы обращения к Economy API внешних плагинов, не готовые серверные плагины |

**В других репозиториях:** города, территория, налоги, казна, роли, охота, данжи и GUI Градостроя. Их доменные данные не принадлежат Economy.

Интеграция: сохранить исходный operationId, выполнить `reserve`, подтверждённую внешнюю мутацию и `commit`; при доказанном отказе — `release`. Неопределённый исход необходимо сверять, а не повторять платёж с новым UUID.
