# Публикация GitHub

Локальный Git-репозиторий создан на ветке main. На машине подготовки GitHub CLI (`gh`) не найден; remote пока отсутствует.
Создавать публичный репозиторий нельзя: в исходном задании запрошена приватная видимость.

Установить официальный CLI: https://cli.github.com/ . Затем выполнить из корня servermine:

```powershell
gh auth login
gh auth status
gh repo create servermine --private --source=. --remote=origin --push
```

Команда создаёт private репозиторий в выбранном аккаунте, добавляет origin и отправляет main.
Если репозиторий с таким именем уже существует, сначала сверить владельца и историю. Не выполнять force push.
Секреты, базы, миры, логи и build не включаются в коммиты.
