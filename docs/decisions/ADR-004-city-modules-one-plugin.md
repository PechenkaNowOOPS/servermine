# ADR-004: внутренние модули Cities, один плагин

Статус: принято из исходного задания.

Каждая функциональная область Cities — отдельный Gradle-проект. cities-plugin собирает их классы и ресурсы в ServerMineCities JAR и связывает зависимости.
Внутренние модули не имеют plugin.yml и не устанавливаются на сервер самостоятельно.

Следствие: модульные границы проверяются при компиляции; одно включение/выключение и одна точка публикации API.
Protection сохраняет изолированный контракт, чтобы позже вынести его без изменения доменных правил.
