# ADR-001: физическая валюта

Статус: принято из исходного задания.

Личные деньги — реальные предметы Minecraft. Economy определяет подлинность по PDC/HMAC, номиналы, размен и денежные операции.
Виртуальный личный баланс не вводится. GUI и внешний вид монеты не подтверждают стоимость.

Следствие: операции с инвентарём выполняются на серверном потоке. Ключ currency.secret необходимо сохранять при резервном копировании.
Изменения номиналов, схемы PDC или ключа требуют отдельной миграции. Журнал нужен для диагностики пограничных сбоев.
