# ADR-002: казной владеет Cities

Статус: принято из исходного задания.

Баланс, права и журнал городской казны принадлежат Cities. Economy владеет только фактическими операциями с физической валютой.
Внесение и вывод будут связываться устойчивой сагой через публичный Economy API.

Следствие: Cities не читает economy.db, Economy не знает города и не хранит их балансы. Покупка за казну и оплата из инвентаря имеют разные доменные правила.
