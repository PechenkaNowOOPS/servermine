# Оригинальный GUI-прототип

Java и YAML в этой папке сохранены из приложений. Они **не входят в Gradle sourceSets и runtime JAR**.
DemoCityRepository и AuditLog являются исторической демонстрацией, а не реализацией города или денежных операций.

Актуальная адаптация находится в ../src/main/java/ru/servermine/cities/gui.
Исходная геометрия слотов, книга, названия экранов и графика сохранены; небезопасные демомутации не подключены.
Оригинальная инструкция: ../../../docs/reference/gui-readme.md (от корня репозитория: docs/reference/gui-readme.md).
