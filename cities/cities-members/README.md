# cities-members

Членство города.

Реализованы приглашения `/smcities invite <игрок>` (только правитель, цель должна быть онлайн; срок действия — 48 часов), принятие `/smcities accept`, выход `/smcities leave` и исключение `/smcities kick <игрок>`. В меню жителей правитель может нажать на запись участника и подтвердить исключение. Каждая мутация проверяет роль и ревизию в SQLite; защита чанков обновляется после изменения состава. Уход правителя атомарно передаёт роль старейшему участнику; исключить правителя нельзя.

Приглашения, исключение участников и настройка ролей остаются в плане.
Модуль включён в единый ServerMineCities JAR; отдельного plugin.yml нет.
