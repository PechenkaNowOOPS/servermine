# cities-members

Членство города.

Реализованы приглашения `/smcities invite <игрок>` (только правитель, цель должна быть онлайн; срок действия — 48 часов), принятие `/smcities accept` и выход `/smcities leave`. Принятие и обновление кэша прав на строительство фиксируются одной SQLite-транзакцией. Уход правителя атомарно передаёт роль старейшему участнику; единственный правитель выйти не может, пока в городе нет преемника.

Приглашения, исключение участников и настройка ролей остаются в плане.
Модуль включён в единый ServerMineCities JAR; отдельного plugin.yml нет.
