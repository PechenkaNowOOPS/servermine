# cities-members

Членство города.

Реализован выход игрока через `/smcities leave`. Уход правителя атомарно передаёт роль старейшему участнику; единственный правитель выйти не может, пока в городе нет преемника.

Приглашения, исключение участников и настройка ролей остаются в плане.
Модуль включён в единый ServerMineCities JAR; отдельного plugin.yml нет.
