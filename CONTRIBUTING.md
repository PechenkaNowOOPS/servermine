# Разработка ServerMineEconomy

Читайте README.md, AGENTS.md и ROADMAP.md. Для изменения экономики создавайте отдельные ветки, добавляйте unit-тесты и выполняйте `./gradlew clean build`.

Проверяйте HMAC/PDC, идемпотентность UUID, переполнения, параллельные возвраты и последствия рестарта. Bukkit-инвентари меняйте на главном потоке, SQL выполняйте вне горячих обработчиков.

Не добавляйте код Градостроя и его ресурспак; эти компоненты принадлежат отдельному проекту. Не публикуйте `currency.secret`, SQLite, логи, миры или build. Выпуск требует проверки на реальном сервере.
