# Разработка

Сначала прочитайте AGENTS.md, README и ROADMAP. Делайте одну законченную задачу на ветку и небольшие логические коммиты.

```bash
git switch -c feature/cities-storage
./gradlew clean build
```

API — неизменяемые значения и маленькие интерфейсы. SQL — внутри собственного домена и вне горячих Bukkit-событий.
Любая денежная/доменная мутация требует стабильного operation ID, текущей проверки прав и понятного восстановления.
Демопрототипы из docs/reference и cities-gui/prototype не подключать к runtime как источник данных.

Перед коммитом: проверить diff, сборку и релевантные тесты. Не добавлять currency.secret, базы, серверные миры, build и локальный JDK.
Изменения gameplay проверять на отдельном сервере по docs/development/server-smoke-test.md.
Описывайте в PR фактическое поведение, проверки и оставшиеся ограничения. Не объявляйте scaffold готовой игровой механикой.
