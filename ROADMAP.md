# План разработки ServerMine

## 0. Подготовка репозитория

- [x] Java 25, Kotlin DSL, Wrapper, фиксированные зависимости.
- [x] Раздельные Economy API / plugin, импорт исходной реализации.
- [x] 16 Cities-модулей и сборка одного runtime JAR.
- [x] Проверки идемпотентности, HMAC, гонки release и доменных правил территории.
- [x] Сохранение GUI и ресурспака; read-only административный предпросмотр.
- [x] Архитектура, ADR, инструкции разработки, CI.
- [ ] Ручная проверка двух JAR на чистом Purpur 26.2.
- [ ] Публикация приватного GitHub remote при наличии GitHub CLI и авторизации.

## 1. Устойчивое ядро Cities — следующая задача

- [ ] Контракты репозитория в core, SQLite-реализация только в storage.
- [ ] Миграции, транзакции, optimistic locking по revision, единственный владелец `(world_uuid, x, z)`.
- [ ] Сохранённые operation ID и нормализованные параметры; повтор и конфликт, чтение после рестарта.
- [ ] Реальный CitiesService, readiness только после успешного запуска хранилища.
- [ ] Тесты рестарта, миграций и одновременных транзакций.

Готовность: данные переживают рестарт; проигравшая конкурентная операция не изменяет город и не оплачивается повторно.

## 2. Основание города и территория

- [ ] Основание с четырьмя свободными соседними чанками; выбор ориентации 2×2 и точки основания в GUI.
- [ ] Политики системных зон и владения; сохранение в одной Cities-транзакции.
- [ ] Реальный выбор соседнего чанка, актуальная цена, права, revision и stage.
- [ ] Журнал саги `reserve -> domain commit -> Economy commit/release` и восстановление.
- [ ] Запрет пятого чанка Поселения, диагональных и разорванных покупок, превышения cap.

Готовность: ошибки в каждой фазе не дают двойной оплаты/территории; неизвестный результат требует сверки с тем же UUID.

## 3. Защита, жители и права

- [ ] Изолированный Protection API и обработчики событий с чтением из кеша.
- [ ] Вступление, приглашение, выход, роли и атомарные разрешения.
- [ ] Проверка прав каждой мутации внутри сервисов, независимо от GUI.

## 4. Казна и прогрессия

- [ ] Баланс и журнал казны в Cities; внесение/вывод физических денег через Economy API.
- [ ] Конфигурируемые требования и цены переходов между этапами.
- [ ] Дерево улучшений без эффектов `+N chunks`.
- [ ] Операционное восстановление UNKNOWN; подробные инструкции для администратора.

## 5. Подключение рабочих GUI

- [ ] Динамическая карта, жители, казна и кнопки поверх настоящих сервисов.
- [ ] Удаление нарисованных демонстрационных значений из рабочих фонов.
- [ ] Защита от устаревших экранов, повторных кликов, disconnect/reconnect, смены прав.
- [ ] Ресурспак и ванильный режим проверены на клиенте при разных GUI Scale.
- [ ] Рынок и дипломатия после проверки ядра и транзакций.

Телепортации на городскую площадь в плане нет.
