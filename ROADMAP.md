# План разработки ServerMine

## 0. Подготовка репозитория

- [x] Java 25, Kotlin DSL, Wrapper, фиксированные зависимости.
- [x] Раздельные Economy API / plugin, импорт исходной реализации.
- [x] 16 Cities-модулей и сборка одного runtime JAR.
- [x] Проверки идемпотентности, HMAC, гонки release и доменных правил территории.
- [x] Сохранение GUI и ресурспака; read-only административный предпросмотр.
- [x] Архитектура, ADR, инструкции разработки, CI.
- [ ] Ручная проверка двух JAR на чистом Purpur 26.2.
- [x] Приватный репозиторий опубликован; ветка `main` настроена на `origin`.

## 1. Хранилище и устойчивое ядро Cities — в работе

- [x] Контракты репозитория в core, SQLite-реализация только в storage.
- [x] Versioned schema, транзакционные миграции, внешние ключи и единственный владелец `(world_uuid, x, z)`.
- [x] Структура journal для операций и городской казны подготовлена к следующим write-use-cases.
- [x] Реальный read-only CitiesService, readiness только после успешного запуска хранилища.
- [x] Транзакционное основание города: SETTLEMENT, основатель-RULER, пустая казна и footprint 2×2.
- [x] Идемпотентный operation ID основания: повтор с теми же параметрами возвращает город; повтор UUID с иным intent конфликтует.
- [x] Проверка мира, world border, системных зон и уникальности игрока/имени/чанков в пути основания.
- [ ] Остальные транзакционные city writes и optimistic locking по revision.
- [ ] Тесты рестарта, миграций и одновременных транзакций.

Подробности уже реализованного slice: [Cities Storage](docs/development/cities-storage.md).

Готовность: данные переживают рестарт; проигравшая конкурентная операция не изменяет город и не оплачивается повторно.

## 2. Основание города и территория

- [x] Основание с четырьмя свободными соседними чанками; сейчас footprint 2×2 строится вокруг опорного чанка.
- [x] Системные запретные зоны и сохранение основания в одной Cities-транзакции.
- [ ] Пользовательский выбор точки/ориентации 2×2 и защита от внешнего владения регионов.
- [x] Выбор свободного соседнего чанка через GUI, цена из конфигурации, право правителя, revision и stage.
- [x] Журнал саги `reserve -> domain commit -> Economy commit/release`; неизвестный итог блокирует повтор.
- [x] Запрет покупки на этапе Поселения, диагональных и разорванных покупок, занятых чанков и превышения cap.
- [ ] Автоматическое восстановление UNKNOWN после рестарта и админ-инструмент сверки.

Готовность: ошибки в каждой фазе не дают двойной оплаты/территории; неизвестный результат требует сверки с тем же UUID.

## 3. Защита, жители и права

- [x] Кэш владений, обработчики ломания/установки/взаимодействия и блокировка разрушения защищённых блоков взрывами.
- [ ] Защита от поршней, потоков жидкости, огня, транспорта и интеграция с внешними регионами.
- [x] Выход участника; уход правителя атомарно передаёт руководство старейшему участнику, последний правитель выйти не может.
- [ ] Вступление, приглашения, исключение участников, настройка ролей и атомарные разрешения.
- [ ] Проверка прав каждой мутации внутри сервисов, независимо от GUI.

## 4. Казна и прогрессия

- [ ] Баланс и журнал казны в Cities; внесение/вывод физических денег через Economy API.
- [x] Настраиваемые цена и минимальные требования перехода SETTLEMENT → VILLAGE; проверка правителя, участников, чанков и ревизии.
- [ ] Настроить требования и цены для последующих переходов между этапами.
- [ ] Дерево улучшений без эффектов `+N chunks`.
- [ ] Операционное восстановление UNKNOWN; подробные инструкции для администратора.

- [x] Мастер основания города из книги: чат-ввод названия, подтверждение стартового footprint, результат из настоящего сервиса.
- [x] Экран повышения Поселения до Деревни с проверкой требований и подтверждением операции.
- [ ] Визуальная карта территории и подключение жителей, казны и остальных кнопок к настоящим сервисам.
- [x] Список доступных соседних чанков, подтверждение покупки и результат из настоящих сервисов.
- [ ] Удаление нарисованных демонстрационных значений из рабочих фонов.
- [ ] Защита от устаревших экранов, повторных кликов, disconnect/reconnect, смены прав.
